# dhsingh735222.github.io

Source code of my personal portfolio website: **https://dhsingh735222.github.io**

The site covers my two years of security work at Wipro (firewall security for Adani Enterprises and CyberArk privileged access for a US healthcare client), my network security and software projects, skills, training and contact details.

## How it is built

- One static `index.html` page with inline CSS and JavaScript. No framework and no build step.
- Fonts from Google Fonts (Archivo, IBM Plex Sans, IBM Plex Mono).
- Light and dark themes that follow the visitor's system setting.
- Responsive layout that works from phone width up.
- Hosted on GitHub Pages from the `main` branch.

## Run locally

Open `index.html` in a browser. No install is needed.
